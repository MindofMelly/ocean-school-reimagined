# Kilombo School homepage redesign

## Goal
Create a polished, organized homepage that preserves Kilombo School’s identity while making **Enroll** and **Donate** the two dominant actions.

## What will change
- Rebuild the home page around an immersive, student-centered opening image and bold educational storytelling inspired by Ocean School’s visual pacing.
- Preserve Kilombo’s existing logo, black/red/green/gold color language, African-centered identity, and core philosophy, vision, and mission copy.
- Add a clean sticky header with clear navigation and prominent **Enroll** and **Donate** actions.
- Organize content into a deliberate sequence: school introduction, mission and philosophy, learning experience, community impact, enrollment invitation, donation appeal, and contact/footer.
- Use existing Kilombo photography and public links where suitable; avoid generic stock imagery.
- Make mobile navigation and calls to action easy to use on smaller screens.

## Interaction and visual direction
- Editorial, energetic, and youth-centered rather than corporate.
- Full-width photography, strong typography, crisp grids, restrained animation, and high contrast.
- Donation and enrollment actions repeat at meaningful decision points without overwhelming the page.
- Existing external donation destination will remain connected; enrollment will link to Kilombo’s current enrollment/application destination when available.

## Technical details
- Build the redesigned homepage at `/` using the existing React application.
- Define all brand colors, typography, spacing, and motion centrally in the site’s design system.
- Add route-specific title, description, and social metadata.
- Verify the finished page in desktop and mobile layouts, including navigation, links, image loading, and text overlap.
